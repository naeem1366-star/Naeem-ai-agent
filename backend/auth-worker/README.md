# Naeem AI Authentication Worker

این سرویس، ورود و ثبت‌نام با شماره موبایل ایران را برای اپ Naeem AI فراهم می‌کند. برای اجرا به وب‌سایت یا دامنه اختصاصی نیاز نیست؛ می‌توان آن را روی نشانی workers.dev منتشر کرد.

## اجزای موردنیاز

1. حساب Cloudflare برای اجرای Worker و ساخت پایگاه داده D1
2. حساب قاصدک و API Key
3. ساخت قالب OTP در پنل قاصدک با حداقل یک پارامتر با نام `param1`
4. مقدار محرمانه تصادفی برای `AUTH_SECRET`

متن پیشنهادی قالب پیامک:

`کد ورود شما به Naeem AI: %param1%\nاین کد تا ۵ دقیقه معتبر است.`

نام قالب باید دقیقاً با مقدار `GHASEDAK_TEMPLATE_NAME` در تنظیمات Worker یکی باشد. متن قالب و نام برند را مطابق ضوابط پنل پیامکی تأیید کنید.

## راه‌اندازی

از پوشه `backend/auth-worker`:

```bash
npm install
npx wrangler login
npx wrangler d1 create naeem-ai-auth
```

شناسه پایگاه داده‌ای که Cloudflare برمی‌گرداند را در `wrangler.toml` به‌جای `REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID` قرار دهید.

سپس:

```bash
npx wrangler d1 execute naeem-ai-auth --remote --file=./schema.sql
npx wrangler secret put GHASEDAK_API_KEY
npx wrangler secret put AUTH_SECRET
npx wrangler deploy
```

برای مقدار `AUTH_SECRET` یک رشته تصادفی بلند و محرمانه بسازید. آن را در اپ اندروید، GitHub یا فایل‌های مخزن قرار ندهید.

در صورت تغییر نام قالب، مقدار `GHASEDAK_TEMPLATE_NAME` در `wrangler.toml` را اصلاح و دوباره Deploy کنید.

## API

### درخواست کد

`POST /v1/auth/otp/request`

```json
{ "phone": "09123456789" }
```

کد شش‌رقمی به مدت ۵ دقیقه معتبر است. فاصله درخواست مجدد حداقل ۶۰ ثانیه و سقف اولیه هر شماره ۵ درخواست در ۲۴ ساعت است. سقف IP نیز ۱۰ درخواست در ساعت است.

### تأیید کد و ورود/ثبت‌نام

`POST /v1/auth/otp/verify`

```json
{ "phone": "09123456789", "code": "123456" }
```

در پاسخ، توکن Bearer سی‌روزه و شناسه حساب برمی‌گردد. کد OTP به‌صورت متن ساده در پایگاه داده ذخیره نمی‌شود و پس از استفاده قابل استفاده مجدد نیست.

### حساب جاری

`GET /v1/me`

هدر:

`Authorization: Bearer <token>`

### سلامت سرویس

`GET /health`

## نکات امنیتی

- کلید قاصدک و راز امضای توکن فقط به‌عنوان Secret در Cloudflare ذخیره می‌شوند.
- کدها ۵ دقیقه اعتبار دارند و پس از ۵ تلاش ناموفق دیگر پذیرفته نمی‌شوند.
- برای هر شماره و IP محدودیت درخواست تعریف شده است.
- پاسخ‌ها از cache شدن منع شده‌اند.
- این نسخه فقط هویت و ورود را پیاده می‌کند؛ کیف پول، خرید، اشتراک و کنترل مصرف API باید در مرحله بعد به همین شناسه کاربر متصل شوند.
- پیش از انتشار عمومی، باید تست واقعی ارسال روی اپراتورهای همراه اول، ایرانسل و رایتل و بررسی تنظیمات ضدسوءاستفاده انجام شود.
