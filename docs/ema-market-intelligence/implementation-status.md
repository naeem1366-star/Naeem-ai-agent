# EMA Market Intelligence — وضعیت پیاده‌سازی

آخرین به‌روزرسانی: 2026-11-27

## انجام‌شده در شاخه آزمایشی

- Migration افزایشی `0011_market_intelligence_foundation.sql` اضافه شد.
- جداول مستقل برای providerها، instrumentها، مشاهدات بازار، کندل‌ها، گزارش تحلیل، jobها، پیش‌بینی‌ها، کارنامه پیش‌بینی، watchlist و هشدارها اضافه شد.
- API فقط‌خواندنی برای catalog، overview، جست‌وجوی instrumentها، quoteها و کندل‌ها اضافه شد.
- موتور محاسباتی قطعی برای EMA20/50، RSI14، MACD، Bollinger Bands، ATR14، نوسان بازده و drawdown نمونه اضافه شد.
- endpoint تحلیل تکنیکال از روی کندل‌های ذخیره‌شده اضافه شد؛ برای تاریخچه کمتر از 60 کندل از تولید تحلیل خودداری می‌کند.
- صفحه فعلی Android به شش دسته بازار نزدیک شد؛ بورس ایران و بورس جهانی تا زمان اتصال منبع معتبر صریحاً unavailable نشان داده می‌شوند.
- workflow بررسی Backend برای شاخه توسعه و PR فعلی فعال شد.

## گام بعدی اجباری قبل از تحلیل واقعی

برای هر شش بازار باید provider matrix ساخته شود و برای هر منبع موارد زیر بررسی و ثبت شود:
1. API رسمی و شرایط استفاده؛
2. مجوز ذخیره، پردازش و نمایش/بازنشر داده؛
3. پوشش کشور، نمادها و نوع بازار؛
4. timestamp، تأخیر، ساعات معاملاتی و SLA؛
5. rate limit و هزینه؛
6. مسیر جایگزین و سیاست stale-data.

تا زمان تکمیل این بررسی، سیستم نباید قیمت یا تحلیل ساختگی تولید کند. هیچ migration remote یا deploy بدون تأیید جداگانه انجام نمی‌شود.
