# EMA Market Intelligence — ماتریس ارزیابی منابع داده

آخرین بررسی: 2026-11-27  
وضعیت: ارزیابی اولیه؛ هیچ منبعی در محیط عملیاتی فعال نشده است.

این سند تصمیم خرید یا تأیید حقوقی نیست. پیش از استفاده تجاری باید متن قرارداد/Terms همان طرح، کشور محل استفاده، نمایش در اپ، ذخیره تاریخچه و حق ارائه داده به کاربران EMA بررسی و ثبت شود.

## جزئیات نامزدها و ریسک مجوز

### 1. CoinGecko — رمزارز
- صفحه قیمت‌گذاری: https://www.coingecko.com/en/api/pricing
- صفحه قیمت‌گذاری، طرح Basic و طرح‌های تجاری را معرفی می‌کند.
- برای استفاده تجاری، attribution با متن «Data provided by CoinGecko» و لینک به API لازم است.
- طبق توضیح مجوز، ادغام داده در محصول مجاز است اما فروش، اجاره، sublicense یا syndication دسترسی به API مجاز نیست؛ white-label/redistribution ممکن است به مجوز Enterprise نیاز داشته باشد.
- نتیجه: نامزد مناسب برای ارزیابی MVP رمزارز، نه منبعی برای بازفروش خام داده.

### 2. CoinMarketCap — رمزارز
- صفحه قیمت‌گذاری: https://coinmarketcap.com/api/pricing/
- طرح‌های پولی شامل commercial use را اعلام می‌کند.
- مجوز استاندارد محدودیت دارد: داده باید جزئی از محصول بزرگ‌تر باشد و نباید به‌صورت سرویس مستقل داده بازتوزیع یا فروخته شود.
- نتیجه: گزینه جایگزین برای مقایسه پوشش، سقف فراخوانی و کیفیت تاریخچه؛ شرایط دقیق استفاده کاربران EMA باید تأیید شود.

### 3. SiftingIO — چندبازاری
- قیمت‌گذاری: https://sifting.io/pricing
- صفحه قیمت‌گذاری، Free را برای prototype/استفاده شخصی و داخلی معرفی می‌کند؛ استفاده تجاری مشتری‌محور در طرح‌های Builder/Pro تعریف شده است.
- قیمت‌های اعلام‌شده در صفحه در زمان بررسی: Crypto/Forex/Commodities از 79 دلار در ماه و US Stocks از 103 دلار در ماه برای Builder با پرداخت سالانه؛ قیمت و شرایط می‌تواند تغییر کند.
- مزیت: پوشش چند asset class و REST/WebSocket در یک حساب.
- ریسک: هزینه چند بازار جداگانه جمع می‌شود؛ free tier را نباید برای اپ تجاری EMA فرض کرد.

### 4. Pyth Network / Pyth Pro — چندبازاری
- فیدها: https://www.pyth.network/price-feeds
- مستندات Pyth Pro: https://docs.pyth.network/pro
- پوشش FX، سهام، رمزارز، فلزات و کالاها را معرفی می‌کند.
- صفحه قیمت‌گذاری/محصول، سطوح دسترسی متفاوتی را از مشاهده محدود تا API و حقوق نمایش/بازنشر توصیف می‌کند؛ دسترسی رایگان Terminal را نباید مجوز API یا نمایش در اپ تلقی کرد.
- نتیجه: از نظر پوشش cross-asset نامزد قوی است، اما قیمت نهایی، مجوز API، نمایش به کاربران EMA و امکان استفاده از داخل زیرساخت ما باید کتبی تأیید شود.

### 5. Tindex — داده‌های ایران
- مستندات توسعه‌دهندگان: https://tindex.app/en/developers/
- مستندات، API توکنی و داده‌هایی از جمله بورس تهران، نرخ ارز، خبر و شاخص‌های اقتصادی را معرفی می‌کند.
- قیمت رایگان API به معنی مجوز تجاری نمایش یا بازنشر نیست؛ Terms، محدودیت درخواست، freshness، تاریخچه و حق cache باید جداگانه تأیید شود.
- نتیجه: گزینه مناسب برای بررسی فنی و تماس با ارائه‌دهنده؛ تا روشن شدن مجوز، صرفاً candidate باقی می‌ماند.

### 6. TSETMC — بورس ایران
- نمونه مستندات فنی ثالث: https://github.com/msmahdinejad/iran-bourse-mcp
- این پروژه endpointهای عمومی TSETMC و Codal را شرح می‌دهد و صریحاً می‌گوید endpointهای غیررسمی ممکن است بدون اطلاع تغییر کنند؛ داده متعلق به صاحبان/بازار مربوط است و باید شرایط بازنشر بررسی شود.
- وجود endpoint عمومی یا کتابخانه متن‌باز، مجوز استفاده تجاری از داده را ثابت نمی‌کند.
- نتیجه: فقط پس از بررسی حقوقی/قراردادی و تست پایداری؛ به‌عنوان fallback هم تا آن زمان فعال نشود.

## آزمون پذیرش هر provider

پیش از فعال‌سازی هر adapter، این مدارک/آزمون‌ها لازم است:

1. URL رسمی API، نسخه API، احراز هویت و نمونه پاسخ واقعی.
2. تأیید کتبی یا Terms روشن برای استفاده تجاری در اپ مشتری‌محور EMA.
3. حق نمایش quote و chart، ذخیره OHLC، محاسبه indicator، cache، تولید گزارش AI و نمایش خروجی به کاربر.
4. محدودیت بازنشر، attribution، سقف کاربران، جغرافیا و sublicensing.
5. پوشش نمادهای موردنیاز و mapping رسمی exchange/symbol.
6. زمان event، زمان provider، زمان ingestion، timezone و trading calendar.
7. نرخ به‌روزرسانی واقعی، تاخیر مجاز، SLA، rate limit، هزینه و overage.
8. تست قطعی/خرابی، داده تکراری، out-of-order، قیمت صفر/منفی، واحد و currency.
9. مقایسه حداقل یک هفته با منبع مرجع مستقل برای همان instrument.
10. ثبت قرارداد، طرح، تاریخ بررسی، attribution و تاریخ انقضای مجوز در registry داخلی.

## مدل داده و جداسازی ضروری

- USD/IRR official، USD/IRR free_market و USD/IRR توافقی باید instrumentهای جدا باشند؛ تبدیل واحد یا ادغام میانگین ممنوع است.
- طلای 18 عیار، مثقال، گرم، سکه امامی، نیم‌سکه، ربع‌سکه، اونس XAU/USD و قرارداد آتی طلا instrumentهای جدا هستند.
- سهام ایران: ریال/تومان و تعدیل‌شده/تعدیل‌نشده جدا.
- سهام جهانی: exchange، currency، session و delayed/live status جدا.
- کالا: spot، futures، contract month، unit و exchange جدا.
- هیچ quote بدون provider، timestamp، currency/unit و quality flag قابل نمایش نیست.

## گام اجرایی بعدی

1. ابتدا دو مسیر فنی را در sandbox ارزیابی کن: Tindex برای داده ایران و CoinGecko برای رمزارز.
2. هم‌زمان از Tindex و providerهای منتخب، مجوز تجاری و حق نمایش/ذخیره را کتبی استعلام کن.
3. برای cross-asset، Pyth Pro و SiftingIO را با نمادهای واقعی موردنیاز EMA از نظر هزینه نهایی و مجوز مقایسه کن.
4. پس از تأیید مجوز و دسترسی، adapter و ingestion محدود برای یک بازار بساز؛ سپس بازار بعدی را اضافه کن.

قانون انتشار: هیچ داده‌ای در اپ به‌عنوان live نشان داده نمی‌شود مگر اینکه timestamp، market session، freshness threshold و SLA منبع آن را تأیید کنند. هیچ قیمت یا forecast ساختگی برای پر کردن UI تولید نمی‌شود.
